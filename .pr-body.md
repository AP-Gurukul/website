## Objective

This pull request completes the massive architectural migration of the Sadhana APPSC website from standard HTML/CSS/JS to a fully componentized **React + Vite** ecosystem. It introduces a highly premium, modern, and engaging user interface designed to maximize conversions for APPSC Group 1 and 2 aspirants.

## Key Changes & Features

### 🏗️ Architecture & Tooling
- **React + Vite Migration**: Replaced the static `index.html` and `styles.css` with a robust Vite build pipeline.
- **Componentized Structure**: Split the monolithic UI into maintainable, encapsulated React components (e.g., `Hero`, `Features`, `LivePreview`, `AppShowcase`, etc.).
- **CSS Modules**: Transitioned from global stylesheets to scoped CSS Modules to prevent style collisions and improve maintainability.
- **Lightweight Routing**: Implemented a custom, lightweight routing solution for legal pages without the overhead of `react-router-dom`.

### 🎨 Premium UI/UX Design
- **Glassmorphism Design System**: Integrated frosted glass effects, subtle semi-transparent borders, and deep shadows for an ultra-premium aesthetic.
- **Dynamic Interactions**: 
  - Mouse-tracking glow effects on feature cards.
  - Smooth parallax scroll animations.
  - Hover states that encourage user engagement.
- **Typography & Color**: Updated the color palette to sleek dark tones mixed with vibrant accents (indigo, emerald) and implemented standard high-readability fonts.

### 📱 Component Highlights
- **Navbar**: Sticky glassmorphic navbar with smooth scrolling for single-page anchor links and intelligent cross-page routing.
- **Hero & Marquee**: High-conversion hero section paired with an infinite, seamless scrolling marquee displaying supported APPSC exams.
- **Interactive Live Preview**: A dynamic tabbed interface showcasing exactly how the app solves user problems (Accuracy, Speed, Strategy).
- **App Showcase**: 
  - Built pixel-perfect phone mockups mirroring the actual app UI (Performance Analytics, Subject Analysis, Detailed Review, AI Insights, Syllabus Tracker).
  - Engineered an **infinite auto-scrolling marquee** for the phone frames that pauses on hover and features premium gradient edge-fades. Removed all aggressive scroll-jacking to ensure native vertical page scrolling works flawlessly on all devices.
- **Pricing & FAQ**: Clean, trustworthy pricing tiers and an accordion-style FAQ section.

### ⚖️ Legal & Policy Pages
- **Terms & Conditions / Privacy Policy**: Integrated comprehensive, professionally formatted legal pages seamlessly into the React layout.
- **Strict Refund Policy**: Drafted and implemented a strict "No Refund" policy tailored for digital goods and subscriptions.
- **Footer Updates**: Removed unregistered company links and replaced them with direct email support links (`appscsadhana@gmail.com`).
